 Kennect Automation Assignment

This repository contains the Selenium automation framework developed for the Kennect assignment. The framework automates key functionalities of the [Kennect web application](https://gor-pathology.web.app/), such as login, patient registration, test creation, and cost calculation with discounts.

---

## 🔧 Tech Stack

- **Java**
- **Selenium WebDriver**
- **TestNG**
- **Maven**
- **Apache POI** (for reading test data from Excel)
- **Page Object Model (POM)** design pattern
